# Golden Retriever Hockey — Round 2

This set contains 30 raster logo concepts generated with OpenAI's built-in image-generation tool.

## Fixed design criteria

- Unmistakable uppercase `G` and `R`
- Broad, compact athletic proportions
- Black, white, and warm athletic gold only
- Retriever and hockey motifs treated as a secondary read
- Flat, vector-friendly presentation on white
- No mockups, gradients, shadows, bevels, or 3D effects
