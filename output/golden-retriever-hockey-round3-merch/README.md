# Golden Retriever Hockey — Round 3 Merchandise Concepts

This set contains 20 black, white, and gold logo concepts generated with OpenAI's built-in image-generation tool. The round intentionally moves beyond initials and uses negative space across symbol marks, badges, and full-name lockups.

## Merchandise criteria

- Thick shapes and wide negative-space channels
- Maximum three inks or embroidery threads
- Strong one-color fallback
- No gradients, shadows, bevels, textures, or 3D effects
- Compact versions for left-chest embroidery and hats
- Wider versions for shirts, hoodies, decals, and coffee mugs

## Production note

These are raster concept explorations, not production vector artwork. After selecting finalists, redraw them as clean SVG/AI/EPS masters, define exact Pantone or thread colors, and test:

- one-color black
- one-color white for dark garments
- two-color black and gold
- embroidery at approximately 1–3 inches
- screen print at approximately 10–13 inches
- mug wrap and decal applications
