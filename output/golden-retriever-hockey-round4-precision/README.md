## Prompt constraints used throughout

- Preserve the selected layout, dog identity, exact text, and black/white/gold palette.
- Correct only dog anatomy, jaw construction, puck geometry, and hockey-stick geometry.
- A hockey stick must have one shaft, a distinct heel, a wider blade, a flat lower edge, and a rounded toe.
- Dog, stick, puck, text, and border receive visible separation unless the negative-space integration is intentional.
- Flat vector-like artwork with crisp edges, thick screen-print-safe forms, and no gradients, shadows, textures, or mockups.

These are high-resolution raster concept refinements generated with the built-in image editing workflow. Once a final direction is selected, it should be manually redrawn as true vector artwork for embroidery, screen printing, vinyl, and scalable merchandise production.
