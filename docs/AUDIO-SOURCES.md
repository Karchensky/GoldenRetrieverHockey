## The Public Domain Mark caveat

Two files (`ice-groan.ogg`, `blades.ogg`) carry **Public Domain Mark 1.0**, not CC0.

The distinction is real and worth stating plainly. CC0 is an author's active waiver of their
own rights. PDM is a *label* asserting a work is already free of copyright worldwide, and
Creative Commons does not recommend it for works that are still in copyright somewhere.
Applied to a field recording made in 2021 or 2024 by a living recordist, PDM is not the tool
CC would have chosen.

What makes these two acceptable: on radio aporee, the licence is picked by the contributor at
upload time from a list of six Creative Commons licences **plus an explicit "public domain"
option**, and aporee's own upload terms state *"your recordings will be published under the
Creative Commons License you've choosen during uploading (which implies that you own the right
to publish it under this licence… you can't revoke or change a licence later, so choose it
carefully."* So the mark reflects a deliberate election by the rights holder, made with notice
that it is irrevocable — it functions as a dedication, not a third party's guess about someone
else's work.

That is a sound basis for use and it imposes no attribution burden. It is nevertheless a
weaker instrument than CC0. If either bed is ever replaced by a true CC0 or commissioned
recording, prefer that.

## Not obtained

**Light snowfall.** No file. Two independent reasons, and neither is solvable by searching harder:
snowfall is very close to acoustically silent — the reason "quiet as snow" is a cliché — so
what circulates under that name is almost always light rain, or hiss. And no CC0 field
recording of it exists on the sources checked; every `snowfall` hit on archive.org's CC0 filter
was music (the jazz standard, a mislabelled live bootleg). A snowfall layer, if wanted, should
be synthesized as fine granular noise rather than sourced.

**Ambient music bed (`music-highq` in the reference).** Not attempted beyond a survey, and
deliberately so. archive.org's CC0 music filter is not trustworthy: the first page of results
included *"The Velvet Underground & Nico [LOORWEN EDITION]"* tagged CC0 1.0, which it plainly
is not. Sourcing a music bed from that pool would mean shipping a licence claim this repo
cannot stand behind. A music bed should be commissioned, bought, or generated — not scavenged.
Note the opener spec §7 lists only field recordings for the beds; music is not required by it.

**Freesound.org.** Nothing retrieved. Freesound requires a logged-in account to download any
file — confirmed on their FAQ: *"To download a sound, first make sure you are logged into your
registered account."* The API additionally requires a token, and full-quality downloads require
OAuth2. There are no credentials for it in this repo or environment, and no anonymous path.
**To use Freesound later:** register an account at <https://freesound.org/home/register/>, then
either download by hand from the sound pages, or create an API key at
<https://freesound.org/apiv2/apply/> and complete the OAuth2 flow for full-quality files.
Filter to "Creative Commons 0" and still verify each sound's own page — the filter is not proof.

## How these files were produced

`ffmpeg` version 8.1.1 (gyan.dev full build). Sources were downloaded to a scratch directory,
never committed — `apps/web/public/audio/` holds only the finished Ogg files.

Each bed: extract the chosen segment → downmix to mono → high-pass (28–60 Hz depending on
material) → seamless-loop wrap → normalise → encode to Ogg Vorbis (`libvorbis`, `-q:a 2–3`,
mono, 44.1 kHz).

**Loop wrap.** From a clip of length `L+X` (crossfade `X` = 2 s):

```
body = C[X : L]                                  # length L-X
xf   = acrossfade(C[L : L+X], C[0 : X], d=X)     # length X
out  = body ++ xf                                # length L
```

The crossfade ends on exactly the content `body` begins with, so `out[L] → out[0]` is
continuous and the loop has no seam.

**Normalisation.** Integrated loudness measured with `ebur128`, then a single static gain to
−23 LUFS, followed by `alimiter` at −1 dBFS. Static gain rather than `loudnorm`'s dynamic mode,
which gates and pumps on sparse ambient material. All beds land within 0.9 dB of each other so
the app can mix them off scroll `T` without per-file trim.

**Verification.** Every shipped loop was checked for a wrap discontinuity by comparing
`|x[0] − x[last]|` against the distribution of adjacent-sample deltas inside the same file. All
five sit inside their own p99.9 — no click. This test is what caught the rejected night-air
bed, and it is worth re-running on any file added here.

## Adding to this file

One row per file, and the row goes in only after the file is downloaded and its licence read on
the item's own page. A search-filter result is not a licence. If something cannot be obtained,
it belongs under "Not obtained" with the reason — this repo has already paid once for an
invented fixture that passed 13/13 tests and produced 1,064 phantom goals. A fabricated licence
row would be the same failure with legal consequences attached.
