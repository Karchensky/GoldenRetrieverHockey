# Golden Retrievers — Concepts 36–50

Built with the retained concepts 21, 28, 32, 33, and 35 as visual anchors.

Every new design uses only `GOLDEN RETRIEVERS`, `GR`, or no text. No concept uses `GRH`.

| No. | Concept | Primary idea |
| --- | --- | --- |
| 36 | Crossed Shield Retriever | Dense heraldic shield with a detailed retriever, full crossed sticks, banners, and puck |
| 37 | Dual Negative-Space Puck | Gold and white retriever profiles arranged around a central puck |
| 39 | Full-Body Oval Crest | Anatomically controlled standing retriever with four visible legs, crossed sticks, and puck |
| 40 | Precision GR Monogram | Clear interlocking `GR`, retriever in the `R` counter, and a taped blade terminal |
| 41 | GR Puck Tag | Front-facing retriever wearing a collar with a puck-shaped `GR` tag |
| 42 | Chevron Stick Crest | Two complete sticks construct a broad inverted-chevron frame around a retriever |
| 43 | Rink Negative-Space Dog | Hockey-rink markings resolve into a minimal retriever profile |
| 44 | Heraldic Twin Retrievers | Mirrored seated retrievers flank a `GR` shield above a full stick |
| 45 | Rink Board Lockup | Wide clipped-corner merchandise plaque with exact team name and stick underline |
| 46 | Keystone Retrievers Patch | Dense keystone patch with faceoff geometry, opposing blades, and a centered puck |
| 47 | Diamond Front Mascot | Symmetrical front-facing dog in a broad diamond with crossed full sticks |
| 48 | Dual Capsule Retrievers | Two facing retrievers, central puck, and a curved team-name banner |
| 49 | Sweater GR Crest | Hockey-sweater-shaped badge with front-facing retriever and clear `GR` |
| 50 | Championship Roundel | Dense circular seal combining the detail of 21 with the frontal symmetry of 33 |

The images are high-resolution raster concepts in black, white, and athletic gold. A selected direction should be redrawn as vector artwork before production embroidery, screen printing, or large-format use.
