## Shared prompt constraints

- Black, white, and athletic gold only
- Clear mature golden retriever anatomy
- Conventional hockey-stick construction: shaft, heel, wider blade, flat lower edge, rounded toe
- Thick screen-print and embroidery-safe shapes
- Strong silhouettes and readable negative space at merchandise-thumbnail size
- No gradients, shadows, 3D, textures, mockups, or watermarks

These are high-resolution raster concept images generated with the built-in image-generation workflow. Selected finalists should be manually redrawn as true vector artwork before production.
