# Majestic Stick-Carry Concepts

Ten black, white, and gold logo directions for Golden Retriever Hockey. Each
concept shows a noble adult golden retriever visibly gripping one ice-hockey
stick in its mouth.

1. `01-regal-profile-medallion.png` — detailed circular profile badge
2. `02-heraldic-shield.png` — diagonal stick in a broad shield
3. `03-front-facing-mascot.png` — symmetrical front-facing team mascot
4. `04-art-deco-diamond.png` — streamlined heritage diamond crest
5. `05-minimal-negative-space.png` — simplified circular negative-space mark
6. `06-ball-in-blade-roundel.png` — tennis ball cradled by the blade
7. `07-horizontal-capsule-tennis.png` — wide merchandise lockup
8. `08-tennis-ball-roundel.png` — enclosing roundel becomes the tennis ball
9. `09-inverted-left-profile.png` — inverted, left-facing alternate
10. `10-front-facing-tennis.png` — minimal front-facing mascot

`contact-sheet-majestic-stick-carry-01-05.png` provides the numbered review
sheet for the original set. `contact-sheet-majestic-stick-carry-06-10.png`
provides the new tennis-ball variations. Concept 07 uses a wide format; the
other individual concepts are 1254 × 1254 PNG files on white.

These are concept rasters. Once a direction is selected, it should receive a
final manual vector pass for production geometry, spot colors, embroidery,
screen printing, and one-color use.
