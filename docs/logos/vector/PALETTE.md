# Production Palette

| Color | Hex | Suggested use |
| --- | --- | --- |
| Black | `#0B0B0D` | Primary outlines, backgrounds, typography |
| White | `#FFFFFF` | Knockouts, highlights, light-garment contrast |
| Athletic gold | `#D9A333` | Retriever artwork, borders, primary accent |

The files in `production-3color-svg` contain only these three fill/stroke colors. The detailed SVG masters retain additional gold and neutral tonal values from the approved concepts.
